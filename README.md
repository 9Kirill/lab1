# Лабораторная работа №1. Класс Matrix

## Назначение класса

`Matrix` — класс, представляющий матрицу целых чисел произвольной размерности.
Инкапсулирует данные (двумерный динамический массив) и предоставляет
безопасный доступ к элементам.

### Основные возможности

- Три конструктора:
  - `Matrix()` — матрица 0×0 (память не выделяется);
  - `Matrix(int size)` — единичная квадратная матрица size×size;
  - `Matrix(int rows, int cols)` — матрица rows×cols, заполненная нулями.
- Доступ к элементам: `get(i, j)`, `set(i, j, value)` с проверкой границ.
- Заполнение: `inputFromKeyboard()`, `fillRandom()` (0..99).
- Вывод: `print()`.
- Вычисление суммы: `sum()`.
- Геттеры: `getRows()`, `getCols()`.
- Дополнительно: `transpose()` — возвращает транспонированную матрицу.

## Что демонстрирует программа

1. Создание четырёх матриц разными конструкторами (0×0, 3×3 единичная,
   3×4 нули, 2×3 нули).
2. Вывод M2, M3, M4.
3. Заполнение M2 по формуле `(i, j) = i * j`.
4. Заполнение M3 случайными числами.
5. Ввод M4 с клавиатуры.
6. Подсчёт суммы элементов M3.
7. Транспонирование M4.
8. Демонстрацию проблемы поверхностного копирования.
9. Демонстрацию исключений (`std::invalid_argument`, `std::out_of_range`).

## Важные особенности реализации

- **Инкапсуляция**: поля `data_`, `rows_`, `cols_` — `private`.
- **Именование**: поля с суффиксом `_`, методы в camelCase.
- **Проверка размерности**: отрицательные размеры → `std::invalid_argument`.
- **Пустая матрица**: если `rows == 0` или `cols == 0`, память не выделяется,
  `data_ == nullptr`. Деструктор это учитывает.
- **Освобождение памяти**: сначала строки `delete[] data_[i]`, потом
  `delete[] data_`.
- **const-методы**: `get`, `print`, `sum`, `getRows`, `getCols`, `transpose`
  не изменяют объект.
- **Инициализация нулями**: `new int[cols_]{}`.
- **`explicit`** у конструктора с одним параметром — запрет неявного
  преобразования `Matrix m = 5;`.

## Известное ограничение

Конструктор копирования и `operator=` по умолчанию выполняют поверхностное
копирование, что приводит к double free. Это будет исправлено в следующих
работах (правило трёх/пяти). В `main.cpp` это продемонстрировано.
